Corrections Policy

Send the article URL, the factual issue and a reliable source to satyaprasadwork@gmail.com.

Review and updates

We compare each request with primary or otherwise reliable evidence. When an error is established, we correct the article; for a significant factual mistake we add a correction note and update the modified date.

When an external source changes its announced plans, we explain the later development instead of silently treating the original statement as a fabrication.
